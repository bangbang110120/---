01

业务背景 — 问题定义与解决思路

📌 项目定位

本项目面向日化美妆行业的中小型商家与品牌运营方，利用真实电商订单数据（天猫、淘宝双十一、日化批发渠道），通过机器学习与数据可视化技术，构建覆盖「诊断 → 预测 → 优化 → 决策」全链路的智能分析平台。

🎯 核心业务问题与解决方案

❌ 问题一：退款率居高不下

电商订单退款率直接影响利润，传统人工经验无法在订单产生时预判退款风险。

✅ 解决方案：训练 XGBoost 退款预测分类器，对每笔订单实时评估退款概率。

📊 效果：模型 AUC 达到 0.984，准确率 99.7%，可精准识别高危订单并前置干预。

❌ 问题二：折扣策略缺乏数据支撑

大促期间（双十一/618）折扣力度靠经验拍板，缺乏「折扣 → 销量 → 利润」的量化分析。

✅ 解决方案：构建价格弹性模型（XGBoost 回归），模拟不同折扣率下的销量与利润变化曲线。

📊 效果：可自动计算最优折扣点，支持「利润优先 / 销量优先 / 平衡模式」三种策略切换。

❌ 问题三：库存管理盲目

哪些商品该补货、哪些该清仓、补多少量——全凭经验，导致滞销积压或热销断货。

✅ 解决方案：销量预测 + 商品热度分级 + 智能补货建议三模型联动。

📊 效果：自动计算安全库存和补货量，支持 30/60/90 天多周期销量预测。

❌ 问题四：套餐搭配依赖人工经验

「搭配套餐」是提升客单价的有效手段，但传统做法靠运营人员手工组合，缺乏数据依据。

✅ 解决方案：构建品类购买共现矩阵 + K-Means 聚类，自动发现高频搭配组合。

📊 效果：基于 7,667 个多品订单生成 20 个数据驱动的套餐建议，支持度量化排序。

❌ 问题五：区域拓展缺少方向

线下地推团队不知道哪些省份/城市存在「有需求但无覆盖」的空白市场。

✅ 解决方案：RandomForest 区域销售潜力预测 + 空白市场扫描。

📊 效果：输出各商品-省份维度的潜力评分，标记高潜力未覆盖区域。

❌ 问题六：用户价值评估模糊

不清楚哪些客户是高价值客户，无法进行分层精细化运营。

✅ 解决方案：RFM 模型（最近消费/频次/金额）自动分群 + 客户画像。

📊 效果：自动识别「重要价值客户」「重要发展客户」等 8 类客群，输出差异化运营策略。

🔍 数据探索 (EDA) 方法

📋 数据质量检查

  • 缺失值检测与填充（数值用 0 / 中位数，分类用众数）
  • 数据类型转换（金额→float，日期→datetime）
  • 异常值识别（负金额、未来日期、零销量商品）
  • 重复订单去重

📈 探索性分析

  • 分布分析：价格分布、金额分布、销量分布
  • 时间趋势：日/周/月维度的订单量与金额变化
  • 地域分布：省份-地市-区县的销售额热力
  • 关联分析：品牌-品类-价格的交叉关系
  • RFM 分群：最近购买/频率/金额三维度客户分层

🛠️ 特征工程核心技术

🔢 数值特征

  • 金额、价格 → log 变换 + 标准化
  • 销量 → 30/60/90 天滚动窗口
  • 时间差 → 付款延迟小时、距今天数
  • 比率 → 销量环比、退款率、转化率

🏷️ 类别特征

  • 省份/地市 → LabelEncoder
  • 商品品类 → LabelEncoder + OneHot
  • 品牌 → 频率编码（高频品牌保留）
  • 商品大类 → OrdinalEncoder

🧬 衍生特征

  • 共现矩阵 → K-Means 聚类特征
  • RFM 分值 → 客户分层标签
  • 金额段 → 分箱离散化
  • 是否周末/时段 → 时间周期
  • 地区退款率 → 聚合统计特征

📊 模型评估体系

分类模型

  • Accuracy（准确率）
  • Precision（精确率）
  • Recall（召回率）
  • F1 Score（调和均值）
  • AUC-ROC（区分能力）

回归模型

  • R² Score（拟合优度）
  • MAE（平均绝对误差）
  • MSE（均方误差）
  • RMSE（均方根误差）
  • MAPE（百分比误差）

聚类模型

  • Inertia（簇内平方和）
  • Silhouette Score
  • 肘部法则自动选 K
  • 簇内共现强度
  • PCA 降维可视化验证

05

项目创新 — 技术亮点与差异化

🥇

创新一：多模型融合择优机制

每个业务问题训练 6-8 种算法（XGBoost、LightGBM、RandomForest、GradientBoosting、LogisticRegression、Ridge、MLP、LSTM），通过统一评估指标自动对比，选择最优模型部署。不是单一模型套用所有场景，而是为每个问题匹配最佳算法。

对比实验 自动择优 70+ 模型文件

🥈

创新二：实时交互式 ML 推理

所有模型在 Streamlit 中实时加载并执行推理，用户调整参数（折扣率、库存阈值、支持度）后预测结果即时更新。区别于静态报表，这是一个可交互的决策辅助系统。

实时推理 参数可调 即时反馈

🥉

创新三：购买共现驱动的套餐推荐

构建 N×N 品类共现矩阵，以共现频率向量为特征进行 K-Means 聚类，在簇内按共现强度生成套餐组合。替代传统人工搭配，每个套餐都有支持度和共现次数作为量化依据。

共现矩阵 K-Means 聚类 量化推荐

🏅

创新四：空白市场智能扫描

用 RandomForest 回归预测商品在各地区的销售潜力，将「高潜力 + 低覆盖」的地区标记为空白市场。为地推团队提供可执行的开荒列表，而非泛泛的市场分析报告。

RF 回归 潜力预测 地推指导

🎖️

创新五：从诊断到决策的完整闭环

平台覆盖 「数据概览 → 诊断分析 → 预测建模 → 策略建议」完整链路。每个分析模块不仅展示数据和图表，更输出可执行的商家赋能建议——例如具体的补货数量、推荐折扣率、套餐组合方案。

闭环系统 可执行建议 端到端

🏆

创新六：异构数据融合分析

将 天猫 B2C 订单、淘宝双十一大促、日化批发渠道三种异构数据源统一处理，在同一个平台中进行跨数据联动分析。不同数据源揭示不同业务维度的洞察。
